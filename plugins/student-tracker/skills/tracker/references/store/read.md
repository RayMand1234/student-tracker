# Store: reads

Reads store nothing (except `takeAlert`'s mark). All take optional `cycle` (an archived address).

- **`readTrainee(tid, since?, retracted?)`** → `{card, evidence, assessments, followups, items, changes, sensitive, entries}`. `since` (`YYYY-MM-DD`) limits Evidence, Assessments and sensitive records by day happened, Entries by day written; default for a brief or question: 6 weeks back. `retracted: true` includes retracted records (only to find a retracted Entry, or when asked what was withdrawn).
- **`readStatus`** → `{cycle, week, active, needTalk, declining, shared, fine}`, active Trainees only, as of today. `week`: Cycle week (days 1–7 of `start` = 1). `needTalk` `[{id, name, days, level}]`: no Talk yet (`days`/`level` null) or days since last Talk ≥ `yellow`/`red` (`level`); no Talk first, then most days, then name. `declining` `[{id, name, drops: [{skill, name, from, to}], status, evalStage}]`: a Trend ↓ (`from` = Rating 28 days ago), Status `concern`, or an evaluation stage; concern first, then in process, then largest drop, then name. `shared` `[{skill, name, trainees: [{id, name, score}]}]`: non-archived Skills rated ≤2 for ≥3 Trainees; most Trainees, then lowest mean, then id; max 2; trainees lowest first. `fine`: other names, sorted.
- **`readPlaybook(tid, skills?)`** → `{targets: [{skill, name, rating, trend, focus, items}], general: [items]}`. Item: `{id, origin: base|commander, kind: sign|tip|exercise|talk-question, skills: [ids]|["general"], band: low|mid|high|null, text}`. Live items: the Commander's own (not retired) first, then base items minus `commander/hides`. `targets`: the given `skills` (`focus: true`), else the Trainee's ↓ Skills then lowest-rated, max 3, archived aside (none if nothing rated). Per target: Rating, Trend (`↑`/`↓`/`null`, as of today), and items tagged to it whose band fits (low 1–2, mid 3, high 4–5; no band fits any; unrated → only no-band items). `general`: items tagged general. Refuses an unknown Trainee or Skill.
- **`takeAlert(pattern?)`** → `{alert, more}`: the one alert for this reply, marked shown today in `meta/alerts`; `more` = others due. `pattern` `{trainee, theme}`: a pattern seen 3+ times for the Trainee just written about (`theme` never stored). Due, in order: `talk` per active Trainee ≥ `red` (most days first; no Talk yet counts from Cycle start), `weakness` per shared weakness (as `readStatus`), the `pattern`, then `talk` ≥ `yellow`. Skipped: a `talk`/`pattern` shown today for that Trainee; a `weakness` already shown for the same Trainee set. `alert`: `null` (nothing written), `{key, kind: "talk", level, trainee, name, days, noTalk}`, `{key, kind: "weakness", skill, name, trainees}` or `{key, kind: "pattern", trainee, name, theme}`. Keys `talk:<tid>`, `weakness:<skill>:<tid,…>` (sorted), `pattern:<tid>`. On write, `meta/alerts` keeps weakness keys of Skills still shared and other keys from today. Refuses an unknown Trainee or empty theme.
