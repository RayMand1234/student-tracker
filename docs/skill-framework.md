# Skill framework (as given by the Commander, verbatim)

Four ordered Stages, each with its Skills. Repeated names in different Stages are separate Skills.

## 1. למידה ותאוריה
- מודעות עצמית
- העמקה והבנה לעומק
- תשומת לב לפרטים
- עצמאות
- סדר וארגון
- שקדנות
- מוטיבציה
- הפקת לקחים ויישום להבא

## 2. הבנת הבעיה
- הבנת הנקרא
- תשומת לב לפרטים הקטנים
- הבנה טובה של הדרישה
- קריאה מעמיקה
- זיהוי של מקרי קצה אפשריים
- הבנה לעומק של מקרי קצה אפשריים

## 3. תכנון הקוד
- חשיבה על הרבה רעיונות
- סדר וארגון
- לדבאג לפני כתיבת הקוד
- חשיבה יצירתית
- מיקוד בדרישה

## 4. מימוש בקוד
- שליטה בסביבת עבודה
- יכולות דיבאג
- חלוקה טובה לפונקציות
- קריאות וסטנדרטים
- חיפוש באינטרנט
- ביקורתיות כלפי קוד
- סדר וארגון

## Interpersonal group (בין-אישי), carried over from trainee-mentoring
- עבודת צוות
- תקשורת
- קבלת ביקורת
- אחריות ואמינות
- עזרה לאחרים

## Rating display
1–5 per Skill per Trainee, colored dark red (1) → vibrant green (5); gray = no evidence yet.
