# קטלוג תרצים (לפי מחזור קודם — ייתכנו שינויים)

המפקד כותב את שמות התרצים בצורות שונות: באנגלית, בתעתיק עברי ("פוב", "דוקר"), או לפי מספר.
כשמזהים תרץ — שומרים בציר הזמן את מה שנכתב **מילה במילה**, ובשדה test את השם הקנוני מהטבלה. אם לא בטוח לאיזה תרץ הכוונה — לתעד כמו שנכתב ולשאול.

שם התרץ מתאר את הנושא/סיפור של התרגיל, לא את החומר הנבחן. לא צריך לדעת מה עושים בכל תרץ — רק לזהות את השם ולתעד איך היה לחניך.

## הערות
- "תרץ 1" לבד הוא דו-משמעי (קיים בכמה מקצועות) — להסיק מההקשר (מה לומדים באותו שבוע לפי claude/course.md), ואם לא ברור — לשאול.
- סקדים: בדרך כלל יותר בתחילת הקורס ופחות לקראת הסוף. אין רשימה קבועה — מתעדים סקד רק כשהמפקד מזכיר אותו.
- פרויקטים (לא תרצים): Interpreter (זוגות, OOP), Padens — מערכת בנק (צוותים 2–4), MZ — פרויקט מסכם של שבועיים.
- תרצים חדשים שהמפקד מזכיר ולא מופיעים כאן — להוסיף לטבלה.
